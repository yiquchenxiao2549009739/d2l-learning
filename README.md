## 在 VS Code 中开始

1. 用 VS Code 打开项目工作区，选择已有 openmmlab 解释器。
2. 先读 `docs/ch07/06_resnet.md` 对应手册的第 1-18 页，再从第 19 页逐段跟做。
3. 按 F5 选择对应小节的“完整演示”，默认使用中文 `--guided` 模式。
