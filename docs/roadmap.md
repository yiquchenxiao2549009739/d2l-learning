# 全书学习路线

按教材顺序，以完整小节或较大的主题块推进，遇到必要的 Python 语法时结合教材补充。每块采用“系统讲解 -> 整合演示 -> 综合实践 -> 集中反馈”的节奏；每个模型采用“公式 -> 小数据 -> 从零实现 -> PyTorch 实现 -> 对比实验”的节奏。用户明确要求不要将 tensor、reshape 等单个函数拆成多轮小课。

不提前承诺固定天数。根据实际作答调整速度，已经掌握的部分快速确认，需要补的部分拆小。

## 学习时间的初步安排

2026-10-08 的计划估计：理解各章主要理论、完成核心实验并能独立写基础训练代码，大约需要 180–300 小时有效学习时间。这是粗略安排，不是速度测量；独立完成全部习题与深入实现所有大型项目需要更久。

| 每个学习日投入 | 预计学习日数量 |
| --- | --- |
| 1 小时 | 180–300 日 |
| 2 小时 | 90–150 日 |
| 3 小时 | 60–100 日 |

按每天约 2 小时安排，考虑休息与复习，可以先预留约 4–6 个月。当前只是完成了较短的入门练习；等能独立写出第一个训练循环，再根据实际困难调整估计。

前期需要补足张量操作、数学和编程基础；后期卷积、循环网络、注意力以及视觉和语言应用的实验更长，不能以相同页数代表相同工作量。

## 每个模型的实验记录

记录问题、输入输出形状、模型、损失、优化器、超参数、训练与验证指标、曲线、错误和解释。比较实验一次只改变一个主要因素。

先用小数据在本机验证。遇到需要较大显存的任务时，缩小数据和模型；不会默认购买云资源。
