# 全书学习路线

按教材顺序推进，遇到必要的 Python 语法时结合教材补充。每个知识点采用“短讲解 -> 预测 -> 手写小练习 -> 运行 -> 解释”的节奏；每个模型采用“公式 -> 小数据 -> 从零实现 -> PyTorch 实现 -> 对比实验”的节奏。

不提前承诺固定天数。根据实际作答调整速度，已经掌握的部分快速确认，需要补的部分拆小。

## 进入教材前

| 小课 | 重点 | 动手任务 |
| --- | --- | --- |
| 00，已快速确认 | 变量、计算、输出 | 已正确预测公式的两次输出，独立编码未验证 |
| 01 | 列表、索引、循环 | 对多个输入逐个预测 |
| 02 | 条件、函数、导入库 | 封装预测函数并理解报错 |

用户要求直接继续教材，因此后两项不作为独立的前置课程；只在需要时补 Python 知识。

## 每个模型的实验记录

记录问题、输入输出形状、模型、损失、优化器、超参数、训练与验证指标、曲线、错误和解释。比较实验一次只改变一个主要因素。

先用小数据在本机验证。遇到需要较大显存的任务时，缩小数据和模型；不会默认购买云资源。
