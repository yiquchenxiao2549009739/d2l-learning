# 教材 1.2.4：反向传播和参数更新分别做什么

这次只理解一次更新。微积分和自动微分的系统讲解在教材第 2 章展开。

## 对上次回答的反馈

“训练损失为 0 不保证新数据预测正确”的核心回答正确。训练表现可以提供参考，但泛化仍需要用未参与训练的数据评估；过拟合是其中一个原因，也可能存在数据分布变化等问题。

“幻觉”通常指生成模型产生看似合理却不真实的内容，和过拟合不是同一个概念。当前例子用泛化表现或过拟合来讨论更准确。

第二项回答提到了反向传播，但需要区分三个步骤：

1. 前向计算：算预测和损失。
2. 反向传播：计算损失对参数的梯度。
3. 优化器：根据梯度和更新规则调整参数。

观察更新后的损失用于评估效果。反向传播计算的是梯度；梯度下降使用该梯度决定局部的更新方向。

## 梯度表示什么

这里只有一个待学习参数 w，梯度就是损失对 w 的导数，表示在当前位置附近，w 增加一点时损失的变化趋势：

- 梯度为正：w 增大一点，损失局部趋于增大；下降方向是减小 w。
- 梯度为负：w 增大一点，损失局部趋于减小；下降方向是增大 w。

多个参数时，梯度由这些偏导数组成。

## 用当前例子计算

固定 x=3、真实标签=10、b=1，只学习 w。

```text
预测 = 3w + 1
损失 L(w) = (3w + 1 - 10)² = (3w - 9)²
```

平方误差对预测值的导数是 `2 × (预测 - 标签)`，预测对 w 的导数是输入 `x=3`。按链式法则相乘：

```text
dL/dw = 2 × (3w - 9) × 3
```

w=2 时，预测为 7、误差为 -3，梯度为 `2 × (-3) × 3 = -18`。这说明此处向增大 w 的方向走一小步，可以降低损失。

若尚不熟悉导数，先理解这个局部方向；第 2 章再系统展开推导。

## 一次梯度下降

```text
新参数 = 旧参数 - 学习率 × 梯度
```

学习率控制步长。设学习率为 0.01：

```text
w_new = 2 - 0.01 × (-18) = 2.18
新预测 = 3 × 2.18 + 1 = 7.54
新损失 = (7.54 - 10)² = 6.0516
```

损失从 9 降至约 6.0516。

梯度描述当前位置附近的趋势。学习率过大时可能越过低点，使损失反而增加；不能用“有反向传播”保证每次更新损失都下降。

## 亲手运行

打开 `lessons/ch01/02_gradient_step.py`，按 F5 选择“第 1 章：一次梯度更新”，或点运行当前 Python 文件。

关键语句：

- `requires_grad=True`：让 PyTorch 记录相关计算，以便求梯度。
- `loss.backward()`：反向传播，计算梯度。
- `w.grad`：读取已经计算出的梯度。
- `w -= learning_rate * w.grad`：执行一次参数更新。
- `with torch.no_grad()`：这次参数更新不记录到求导用的计算图中。
- `.item()`：把只有一个元素的张量取成普通 Python 数值，方便输出。

先原样运行；再把 `learning_rate=0.01` 改成 `0.2`，保存并从头运行。两次均从 w=2 开始。
