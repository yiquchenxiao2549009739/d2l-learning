## 从手写公式走向学习参数

刚才的 `y = w * x + b` 已经可以计算输出，但 `w` 和 `b` 是人直接指定的。

机器学习的训练过程，是利用数据和反馈来调整模型参数，使预测更符合数据。程序员仍需要选择模型结构、目标和优化方法，并写出训练程序；数据参与确定最终的参数。

深度学习使用包含多层数据变换的神经网络来学习更复杂的关系。当前使用一个简单线性模型理解学习过程，后面再进入多层模型。

## 四个组件

先看一条用于教学的合成数据：输入为 3，真实输出为 10。

| 组件 | 含义 | 当前例子 |
| --- | --- | --- |
| 数据 | 给模型学习的样本 | 特征 `x=3`，标签 `y_true=10` |
| 模型 | 把输入变成预测的规则 | `y_pred = w * x + b`，参数为 `w、b` |
| 目标 / 损失函数 | 量化模型预测的好坏 | 平方误差 `loss = (y_pred - y_true) ** 2` |
| 优化算法 | 根据损失调整参数的方法 | 寻找使训练数据上损失更小的参数；后面学习梯度下降 |

`x` 是特征，`y_true` 是真实标签，`w、b` 是模型参数，`y_pred` 是预测结果。训练时，它们承担的角色不同。

## 用数字理解损失

初始参数 `w=2, b=1`，输入 `x=3`：

```text
预测：2 × 3 + 1 = 7
标签：10
误差：7 - 10 = -3
平方误差：(-3)² = 9
```

如果只把 `w` 改为 3，预测变成 10，当前样本的平方误差变成 0。这个候选参数在当前样本上更好。

平方的作用之一是避免正负误差相互抵消。Python 中 `** 2` 表示平方。这个例子只有一个样本，所以直接计算该样本的平方误差；多个样本的训练通常会汇总或平均各自的损失。

这次手动改参数是为了观察效果。真正训练会让优化算法重复执行“预测 -> 计算损失 -> 调整参数”。

## 亲手修改参数

打开 `lessons/ch01/01_learning_components.py`：

```python
x = 3
y_true = 10
w = 2
b = 1

y_pred = w * x + b
loss = (y_pred - y_true) ** 2

print("预测值：", y_pred)
print("平方误差：", loss)
```

1. 原样运行，观察预测和损失。
2. 先预测，只把 `w = 2` 改成 `w = 3`，保存并重新运行。
3. 在聊天中报告两次输出，并解释哪一组参数更好。
4. 使用 `exercises/ch01/01_learning_components.py` 尝试另一条数据，选择参数并填写平方误差公式。

只为了让损失变小而篡改真实标签，不能让模型获得正确的预测能力。训练通常调整 `w、b`，而不是修改这条观测的 `x、y_true`。

## 训练与预测，以及新数据

训练：已知输入与标签，调整参数。

预测：使用给定参数，从新输入计算输出；做预测时可能尚不知道真实标签。

当前一个样本上损失为 0，并不能证明模型能处理其他输入。后面会用更多样本训练，用未参与训练的数据检查泛化；教材 1.2.3 已开始引入训练集、测试集与过拟合。
