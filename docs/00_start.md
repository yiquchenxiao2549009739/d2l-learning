# 第 00 课：用 Python 表达一个公式

今天的目标只有三个：看懂赋值，写出计算式，打印结果。暂时不用安装新软件，也不用理解整个项目。

## 先预测

```python
x = 3
w = 2
b = 1
y = w * x + b
print(y)
```

先在聊天里回答：程序打印多少？如果把第一行改成 `x = 5`，然后从头运行，打印多少？

## 每一行是什么意思

`x = 3`：把右侧的数值 3 赋给名字 `x`。这里的 `=` 是赋值操作。

`w = 2` 和 `b = 1`：同样给另外两个名字赋值。

`y = w * x + b`：先算右侧，再把结果赋给 `y`。`*` 表示乘法，乘法先于加法。

`print(y)`：把 `y` 当前的值输出到终端。括号中的 `y` 没有引号，所以取的是变量的值。`print("y")` 输出的是文字 y。

Python 按顺序执行这些语句。程序中的 `y` 保存的是计算时的结果；以后只改变 `x`，不会让旧的 `y` 自动重新计算。

`#` 后面的内容是注释，用来给人解释代码，Python 不执行它。

## 连接教材

把公式想象成一个非常简单的预测规则：输入 `x`，得到预测 `y`。

- `x`：输入，例如某个测量值。
- `w`：输入变化一单位时，预测变化多少。
- `b`：当输入为 0 时，这个公式给出的预测。

这里的 `w`、`b` 是我们手动指定的。后面训练线性回归时，将用数据和损失函数来调整它们。今天先把这条公式写成代码。
