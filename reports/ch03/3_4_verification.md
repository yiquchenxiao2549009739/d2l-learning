- 最终训练 CE=0.08761749161776983，accuracy=0.975；验证 CE=0.09385067247500177、accuracy=0.9666666666666667；测试 CE=0.0735096514478257、accuracy=87/90。测试仅报告固定默认方案，不用于挑选超参数。
- NumPy 独立按同一批次重放全部更新，最大参数误差 4.441e-16；逐轮训练/验证 CE 最大误差 1.110e-16，准确率差为 0。人工 CSV 与种子生成张量逐元素一致；混淆矩阵由 NumPy 独立重算一致。
- logits 中心差分步长 1e-5：一阶梯度误差 1.096e-11；对 softmax 梯度差分得到 Hessian，与自动求导最大误差 6.104e-12。

## 数学和 API

- 手写减行最大值的 softmax 与内置版本一致，概率行和为 1；argmax 前后相同，同一行平移常数不变。温度改变分布，最大项不变。
- 整数索引 CE、独热软标签 CE 与 log_softmax 后取真类负对数的平均值一致。两个示例的平均 CE=0.28872599200033305；梯度等于 (P−Y)/2。
- 极大/极小得分的直接指数会得到非有限结果，稳定 softmax 正常。得分 [1000,0,-1000]、真类 2 的显式概率下溢为 0，稳定 CE 仍为 2000。未把 softmax 概率重复传给 CrossEntropyLoss 作为正确做法。
- 单样本 Hessian 与 diag(p)−pp.T、独热随机向量协方差一致；检查半正定与行和为零。数学解释限定为对 logits 的曲率。
- 熵/交叉熵/KL 恒等式及 nat/bit 换算核对。三类等概率固定块码使用整数不等式 2^b≥3^n>2^(b−1) 验证最小位数；全部 27 个三符号组合的五位码独立往返验证。
- 平滑最大/最小值在 λ=1/2/5/10/100 下检查范围，数学证明给出一般 C 类边界与极限，明确浮点舍入和概率向量/标量的区别。
